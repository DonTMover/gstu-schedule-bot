# Документация по использованию бота gstu-schedule-bot

Бот предназначен для:
- Просмотра расписания группы (c выбором подгруппы)
- Просмотра расписания преподавателя
- Поиска групп и преподавателей через inline-режим
- Выставления и просмотра рейтингов преподавателей (0–5⭐)
- Навигации по неделям (предыдущая / следующая)
- Кэширования ответов, чтобы снизить нагрузку на API

## 1. Старт и дисклеймер

При первом запуске (команда /start или нажатие «Start» у бота):
Бот отправляет дисклеймер + кнопку:
```
Принять
```
До принятия условий функционал недоступен.

После нажатия:
```
Спасибо за принятие условий. Теперь вы можете выбрать группу.
[ Поиск группы ]
[ Рейтинг преподавателей ]
[ Поиск расписания преподавателя ]
```

## 2. Основная клавиатура (inline-кнопки)
После принятия условий доступно меню:
- Поиск группы → открывает inline-поиск (см. ниже) с префиксом `group:`
- Рейтинг преподавателей → inline-поиск `teacher:`
- Поиск расписания преподавателя → inline-поиск `teacher_schedule:`

## 3. Выбор группы

Через inline-поиск (см. раздел 6) пользователь выбирает группу. Бот получает сообщение вида:
```
Вы выбрали группу: АП-11 (ap-11)
```
Реакция бота:
1. Сохраняет (в БД) user_id → group_name
2. Запрашивает выбор подгруппы:
```
Подгруппа 1 | Подгруппа 2
```

### Подгруппа
После нажатия (например «Подгруппа 1»):
```
✅ Ваша подгруппа: 1
Теперь выберите день недели:
[Понедельник] [Вторник]
[Среда]       [Четверг]
[Пятница]     [Суббота]
[Прошлая неделя <--] [Следующая неделя -->]
[Вернуться]
```

## 4. Получение расписания группы

Выбор дня (например «Среда») → бот:
1. Берёт сохранённую группу + подгруппу
2. Получает расписание (кэш или API)
3. Форматирует и отправляет:
```
📅 Среда, 18.09.2025  •  Неделя: EVEN

1. Математика (Мат.)
🕒 08:00 – 09:35
👨‍🏫 Преподаватель Ф.И.О.
🏫 302
👥 АП-11

2. Программирование (Прогр.)
...
```
Если занятий нет:
```
📅 Понедельник, 22.09.2025  •  Неделя: ODD

Занятий нет 🎉
```

### Перелистывание недель
Кнопки:
- «Прошлая неделя <--»
- «Следующая неделя -->»

Меняет внутреннюю привязку выбранного понедельника и перерисовывает последний выбранный день без запроса нового дня вручную.

## 5. Просмотр расписания преподавателя

Шаги:
1. Inline-поиск с префиксом `teacher_schedule:` (см. раздел 6)
2. Пользователь выбирает преподавателя → сообщение:
```
Преподаватель: Иванов Иван Иванович
```
3. Бот сохраняет имя + slug преподавателя и предлагает:
```
Выберите день недели...
```
4. Выбор дня аналогичен группам, но вывод:
```
📅 Четверг, 19.09.2025  •  Неделя: EVEN

1. Технологии (Тех.)
🕒 10:00 – 11:35
👥 Группы: АП-11, АП-21
🏫 Кабинет: 210
```

## 6. Inline-поиск

Пользователь вводит в строке набора сообщения (в любом чате или в чате с ботом):
- `@username_bot group:АП` → список групп, где есть «АП»
- `@username_bot teacher:иван` → преподаватели (с рейтингом)
- `@username_bot teacher_schedule:иван` → преподаватели (только имя, без рейтинга)

### Inline-ответы (варианты)
1. Группа найдена:
```
Группа: АП-11
(Описание: Код группы: ap-11)
```
2. Группа не найдена:
```
Группа не найдена
(Описание: Нет такой группы.)
```
3. Преподаватель (режим рейтинга):
```
Иванов Иван Иванович
Рейтинг: 4.33/5, оценок: 12
```
4. Преподаватель (для расписания):
```
Иванов Иван Иванович
Преподаватель
```

## 7. Рейтинг преподавателей

Если выбрать преподавателя через режим `teacher:` — бот отправит сообщение:
```
Преподаватель: Иванов Иван Иванович
⭐ Текущий рейтинг: 4.33/5
```
И клавиатуру:
```
0️⃣ | ⭐ | ⭐⭐
⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐
```
Нажатие:
- Ставит/обновляет оценку (0–5)
- Пересчитывает среднее (AVG, COUNT)
- Обновляет сообщение в чате

Ответ всплывающим уведомлением:
```
Вы установили 5⭐!
```

Хранение:
- Таблица `teachers`
- Таблица `grades` (уникальность по (teacher_id, user_id))

## 8. Команды

| Команда | Описание |
|---------|----------|
| /start | Приветствие + дисклеймер + меню |
| /test_get_id | Возврат ID пользователя (внутренний тест) |

Прочие сообщения обрабатываются как результаты inline-вставок.

## 9. Кнопки callback и их логика

| Callback data префикс | Назначение |
|-----------------------|------------|
| disclaimer:accept | Принятие условий |
| subgroup:N | Выбор подгруппы |
| day:MONDAY... | День расписания группы |
| teacher_day:MONDAY... | День расписания преподавателя |
| week:prev / week:next | Навигация по неделям (для групп) |
| rate:hash:value | Оценка преподавателя |
| comeback | Возврат к главному меню |

## 10. Сохранение состояния

| Хранилище | Назначение |
|-----------|------------|
| PostgreSQL (users) | user_id, group_name, subgroup |
| PostgreSQL (teachers, grades) | Преподаватели + оценки |
| Redis | Кэш расписаний (группа, подгруппа, преподаватель) |
| В памяти (dict) | user_teacher, user_week, user_day (временное, теряется при рестарте) |

## 11. Взаимодействие с API

| Тип | Endpoint |
|-----|----------|
| Расписание группы | https://sc.gstu.by/api/schedules/group/{slug} |
| Расписание подгруппы | https://sc.gstu.by/api/schedules/subgroup/{slug}-{subgroup} |
| Расписание преподавателя | https://sc.gstu.by/api/schedules/teacher/{slug} |

Все запросы:
- User-Agent рандомизируется
- Устанавливается X-Id + Cookie (_tid)
- Кэшируются на 2 суток (по умолчанию)

## 12. Форматирование расписания (ключевые поля)
Извлекаются:
- lessonNumber
- startTime / endTime
- subject.name / subject.shortName
- teachers[].fullName (группы) или groups[].name (преподаватель)
- classrooms[].roomNumber
- weekType вычисляется (EVEN/ODD) по ISO-неделе
- Дата дня в рамках текущей (или переключённой) недели

## 13. Типовые сценарии

### Сценарий: посмотреть расписание группы
1. /start → принять
2. Поиск группы → выбрать
3. Выбрать подгруппу
4. Нажать день → получить пары
5. Листать недели

### Сценарий: оценить преподавателя
1. Inline: `@bot teacher:иванов`
2. Выбрать преподавателя с рейтингом
3. Появляется сообщение + клавиатура
4. Нажать количество ⭐

### Сценарий: расписание преподавателя
1. Inline: `@bot teacher_schedule:иван`
2. Выбрать преподавателя
3. Появляется меню дней
4. Нажать день

## 14. Возможные сообщения об ошибках
| Сообщение | Причина |
|-----------|---------|
| Преподаватель не найден в базе. | slug не найден |
| Сначала выберите группу, используя команду /start | Пользователь не зарегистрирован (нет записи в users) |
| 📅 Расписание пока недоступно. | Ошибка запроса API |
| Группа не найдена... | Inline-поиск без совпадений |

## 15. Ограничения и поведение
- Состояние недели (user_week) не сохраняется в БД
- Кэш в Redis может отдать устаревшие данные до 2 суток
- Переоценка преподавателя перезаписывает прежнюю оценку
- Хеш преподавателя (hash) используется для callback ID

## 16. Переменные окружения (важное)
| Переменная | Назначение |
|------------|-----------|
| BOT_TOKEN | Токен Telegram бота |
| DATABASE_URL | Подключение PostgreSQL |
| REDIS_URL | Подключение Redis |
| PROXY | (опционально) прокси для запросов к API |
| BACKUP_DIR | (опционально) каталог JSON-бэкапов миграции, по умолчанию `backups` |

После принятия дисклеймера пользователь выбирает интерфейс расписания:
подробный (текущий) или минималистичный. Изменить выбор можно командой `/interface`.

## 17. Пример пользовательского потока (сводно)

```
/start
→ Принять
→ Нажать "Поиск группы"
→ Ввести: @bot group:АП-11
→ Выбрать "Группа: АП-11"
→ Выбрать "Подгруппа 1"
→ Нажать "Среда"
→ Получить расписание
→ Нажать "Следующая неделя -->"
→ Перерисовка того же дня следующей недели
```
